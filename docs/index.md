# AulaDesk

!!! warning "Proyecto en desarrollo"

    AulaDesk está en la etapa de análisis y diseño inicial. Todavía no hay una versión utilizable, y AulaDesk es un nombre temporal.

AulaDesk es un cliente de escritorio para Moodle, para Windows y Linux. Se conecta a cualquier instancia de Moodle mediante su API oficial, con un login persistente como el de la app móvil, y agrega integraciones con el sistema operativo: notificaciones, descargas automáticas y calendario.
